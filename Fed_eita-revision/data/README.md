# Datasets (not redistributed)

1. **TON-IoT** (network dataset, `Train_Test_Network` file, 461,043 flows), UNSW Canberra:
   https://research.unsw.edu.au/projects/toniot-datasets
   Save it as `data/TON_IoT_Train_Test_Network.csv`.

2. **Edge-IIoTset** (ML-EdgeIIoT-dataset CSV, 157,800 rows), IEEE DataPort:
   https://ieee-dataport.org/documents/edge-iiot-dataset-comprehensive-realistic-cyber-security-dataset-iot-and-iiot-applications
   Save it as `data/ML-EdgeIIoT-dataset.csv`.

Set `TON_CSV` and `EDGE_CSV` if you use other paths.
